Setup guide

iPhone apps are unsigned IPAs: sign them with your own Apple ID using Sideloadly or AltStore.

Built so your login stays yours

SSC never asks for or stores a password. You sign in in a normal browser window, and what SSC keeps is guarded by your system.

🔐

Secrets in the OS vault

Session data and the Parent link live in the macOS Keychain, Windows Credential Manager or Linux Secret Service – never in plain files. Browser sign-in sessions are deleted after every sync.

👀

Read-only Parent mode

The wall-display page can't change anything and answers only your home network. It never contains messages or sign-in data, and you can rotate its link any time.

📲

Key that stays on the phone

SSC Mobile keeps its Untis Mobile key on this device only – not in iCloud, not in backups – behind Face ID or your passcode, with no way to show or export it.

Honest limits. An app that logs in has to hold its key in memory for a moment, so nothing can be "impossible to extract" on a compromised device. SSC uses WebUntis's internal, undocumented endpoints; your school can change or block them, and the Untis Mobile login only works if your school allows it.

Questions

Is this official?

No. SSC is an independent open-source project, not affiliated with or endorsed by Untis GmbH (WebUntis), Microsoft or Apple. It reads only your own account.

Why “Stundl”?

From the Austrian-German Stunde (lesson) with a friendly diminutive ending. English speakers can say SSC Student Client.

Will it work with my school?

If you can sign in to WebUntis in a browser, the desktop apps can sync. SSC Mobile and the autonomous Home Assistant mode additionally need your school to have Untis Mobile switched on.

What does it cost?

Nothing. It's MIT-licensed – see the license.
